## Features

### 카테고리 & 트렌딩 피드

`기술` · `회고` · `일상` 카테고리와 최신·트렌딩 정렬로 관심 있는 주제의 글을 발견합니다.

<p align="center">
  <img src="docs/assets/readme/feature-feeds.gif" alt="카테고리 및 트렌딩 피드 탐색" width="840" />
</p>

### 문장 위에서 시작되는 인라인 댓글

이야기하고 싶은 문장을 선택해 그 자리에 댓글을 남기고, 인용 문장을 눌러 본문 위치로 바로 이동합니다.

<p align="center">
  <img src="docs/assets/readme/feature-inline-comments.gif" alt="인라인 댓글 워크스페이스" width="840" />
</p>

### 글쓰기에 집중하는 에디터

`#`으로 제목을 열고, `/`로 인용구를 찾거나 `/토글`을 입력해 토글 목록을 만드는 등 키보드만으로 블록을 빠르게 작성합니다.

<p align="center">
  <img src="docs/assets/readme/feature-editor.gif" alt="마크다운 단축키와 슬래시 블록 에디터" width="840" />
</p>

### 개인 블로그와 팀 블로그 Colog

개인 블로그는 **시리즈**로, 팀 블로그 Colog는 **챕터**로 글을 엮어 기록을 쌓습니다.

<p align="center">
  <img src="docs/assets/readme/feature-blog-colog.gif" alt="개인 블로그 시리즈와 Colog 챕터 탐색" width="840" />
</p>

### 정기 발행 매거진 The Rilog.

매일 오전 6시에 업데이트되는 Daily Headlines와 큐레이션 아티클로 기술 흐름을 읽습니다.

<p align="center">
  <img src="docs/assets/readme/feature-the-rilog.gif" alt="The Rilog. 매거진 탐색" width="840" />
</p>

### 모바일에서도 이어지는 경험

이동 중에도 피드를 탐색하고, 하단 시트에서 문장별 인라인 댓글 대화를 확인합니다.

## Getting Started

| 1. GitHub로 시작 | 2. 개인 블로그 기록 | 3. Colog 함께 운영 |
| :--- | :--- | :--- |
| GitHub 계정으로 바로 로그인하고 나만의 블로그 주소(`/@slug`)를 만듭니다. | `/` 슬래시 에디터로 글을 작성하고 시리즈로 묶어 아카이빙합니다. | 팀 블로그 Colog를 개설해 멤버를 초대하고 챕터별로 팀의 여정을 남깁니다. |
