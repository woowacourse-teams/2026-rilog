# ADR 0019: 이미지 자산과 사용처 참조 코드 제거

- 상태: 승인
- 날짜: 2026-10-28
- 소유자: Backend
- 대체: ADR 0017

## 결정과 영향

이미지 업로드 URL 발급 시 자산을 DB에 등록하지 않고 자산·참조 엔티티와 저장소를 제거한다. 업로드 API의 응답 형식, 객체 키와 S3 태그 정책은 유지하므로 프론트엔드 변경은 필요하지 않다. ADR 0017에서 계획한 참조 기반 정리·압축 수명주기는 적용되지 않는다. 기존 태그 처리에서 같은 이미지를 여러 사용처가 공유할 때 발생할 수 있는 문제는 남는다.

이미 적용된 Flyway V8은 검증을 위해 보존하며 기존 테이블과 데이터도 삭제하지 않는다. 테이블 정리가 필요하면 데이터 보존과 배포 영향을 검토한 후 별도 마이그레이션으로 처리한다. 기존 데이터는 이 코드에서 더 이상 읽거나 갱신하지 않는다.
