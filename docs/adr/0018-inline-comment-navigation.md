# 인라인 댓글에서 본문 인용 위치 확인

## 배경

댓글 목록에서 본문으로 돌아갈 때 이동한 문장이 화면에 보여도 인용 범위를 바로 식별하기 어렵다. 화면 폭이나 글꼴이 바뀌면 밑줄은 다시 계산된다.

## 결정

- `본문으로 이동`은 전체 화면 사이드바가 실제로 닫히고 포커스가 복원된 뒤 해당 인용으로 이동한다. 넓은 화면의 도킹 패널은 열린 상태를 유지한다.
- 기존 밑줄과 네이티브 텍스트 선택을 유지하면서 정확한 인용을 1초 강조하고 0.5초 동안 지운다. 동작 줄이기 설정에서는 즉시 이동하고 1초간 정적으로 강조한다.
- 다시 계산된 밑줄에도 원래 강조 종료 시각을 적용한다. 반복 이동·새 댓글 진입·화면 이탈 시 이전 강조를 정리한다.
- `OUTDATED` 인용은 기존 정책대로 본문으로 이동하지 않는다. 공개 URL·API·분석 계약은 바꾸지 않는다.

## 검증 경계

실제 상세 경로에서 모바일 및 PC 진입, native dialog 종료, 정확한 인용 범위와 화면 재측정 후 강조 복귀를 브라우저에서 검증한다. 데스크톱 엔진 자동화는 실제 iOS·Android 기기의 입력이나 키보드 동작을 대체하지 않는다.
