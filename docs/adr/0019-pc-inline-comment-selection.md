# ADR 0019: PC 인라인 댓글 직접 선택

- 상태: 채택
- 관련 이슈: #782

## 배경

PC에서 기존 텍스트 선택 툴바 외에 댓글 작성 진입점을 제공하면서 본문의 읽던 위치와 기존 인용 표시를 유지한다.

## 결정

- PC 플로팅 버튼으로 직접 선택 모드를 시작한다. 본문을 단일 허용 블록 내에서 드래그하고 선택 끝의 댓글 쓰기로 확정한다.
- 선택 중 문서 스크롤과 링크 실행을 잠그되 스크롤바 공간과 기존 밑줄을 유지한다. 기존 밑줄의 호버·클릭과 블록 버튼 반응은 일시 중단한다.
- 선택 모드와 댓글창은 같은 History 소유자를 사용한다. 선택 확정은 같은 이력을 댓글 작성으로 전환하고 취소와 뒤로가기는 읽던 상태로 복귀한다.
- 인증 복귀에서 선택 범위와 `floating_button` 진입점을 보존한다. 기존 UTF-16 범위·블록·ACTIVE 인용 재사용 정책을 따르며 선택 텍스트는 분석으로 보내지 않는다.
- 화면 밖 문장 선택과 자동 스크롤은 범위 밖이다. 실제 OS별 선택 및 키보드 동작은 브라우저 자동화와 구분해 검증한다.
